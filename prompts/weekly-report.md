# 週報ドラフト生成プロンプト (コピペ用)

作業記録 (TODO.md / 台帳 / git log) から週報ドラフトを作る定型プロンプト。
AI アシスタントのあるプロジェクトで、そのまま貼り付けて使う。

---

今週の作業報告のドラフトを作ってください。

材料:
1. `git log --since="1 week ago" --oneline --author=$(git config user.email)` の結果
2. TODO.md の変更 (`git diff HEAD@{1.week.ago} -- TODO.md` があれば)
3. fix-session-*.md など今週更新された作業台帳

形式:
## 今週の成果
- (完了したこと。成果物・コミットを 1 行ずつ。技術的成果は「何ができるようになったか」で書く)

## 進行中
- (着手済み・未完了のもの。現在の状態と残作業)

## 課題・相談
- (詰まっている点、判断が必要な点)

## 来週の予定
- (台帳・TODO から推測されるもの。推測には「(予定案)」と付ける)

ルール:
- 事実 (コミット・記録にあるもの) と推測を区別する
- 関係者が読む前提で、過度な技術詳細は避けて 1 項目 1〜2 行
- 日本語。数字と括弧は半角
