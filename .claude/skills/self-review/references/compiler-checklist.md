# コンパイラパッチ レビューチェックリスト (ターゲット非依存)

X86 / RISC-V / その他どのターゲットの作業でも共通で確認する観点。
self-review Skill の「影響範囲」「重点確認ポイント」を書くときに使う。

## 1. 変更の置き場所
- [ ] ターゲット固有の修正をターゲット非依存の共通部に入れていないか (逆も)
- [ ] フロントエンド/最適化/backend のうち、本来直すべき層で直しているか
- [ ] 同じロジックが既に存在しないか (upstream のユーティリティ、既存ヘルパ)

## 2. 正しさ
- [ ] ABI に影響するか (引数渡し、レジスタ割当、スタックレイアウト、アラインメント)
- [ ] 型の端 (i1/i128、ベクトル、poison/undef) で成り立つか
- [ ] 符号拡張/ゼロ拡張の取り違えがないか
- [ ] 最適化レベル (-O0/-O2) や Debug/Release ビルドで挙動が変わらないか

## 3. 波及
- [ ] 他ターゲットのコード生成/テストに影響しないか
- [ ] 既存のオプション/フラグの意味を変えていないか
- [ ] upstream 追従方針と矛盾しないか (upstream との差分を増やす価値があるか)

## 4. テスト
- [ ] 修正を検証する lit テストを追加/更新したか
- [ ] テストは「修正前に失敗し、修正後に通る」ことを確認したか
- [ ] CHECK 行は生成コードの本質を検証しているか (レジスタ番号など壊れやすい部分に依存していないか)

## 5. 記録
- [ ] commit message に根本原因と修正方針が書いてあるか (英語)
- [ ] Claude の co-author / generated 表記を入れていないか
- [ ] 関連 issue / upstream レビューへの参照があるか
