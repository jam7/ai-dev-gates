# 70: 実データを取り込まない

きっかけは実事故。公開予定の repo から蔵書の ID 5 種を除去するのに
filter-repo を 1 回 (169 箇所・65 リビジョン) 走らせた。その後、別の測り方で
**話タイトル 4 件と実掲載日時 22 種**が出てきた。取り込みは 1 行、除去は
1 件ずつの判定で、履歴に入るたび書き換えが要る。しかも**判定できるのは実データと
突き合わせられる人だけ**で、後から読む人には実物とダミーの区別が付かない。

この文書の悪い例はすべて合成値で書いてある (DATA-2 と DATA-4 をこの文書自身にも
適用している。実物を引用した瞬間、このファイルが漏れ口になる)。

### DATA-1: 観測した値をそのまま書かない [MUST] [構造]
- 対象: 全言語。テストコード・テストデータ・ドキュメントの例・コメント内の
  引用を含む
- 規則: 実在のシステム・アカウント・作品・利用者から観測した文字列を、コードや
  文書にそのまま書かない。**観測した場所で置換してから持ち込む**。置換先は
  宣言済みの語彙 (`tools/test-vocabulary.txt` 等) から選び、無ければ足す
- 理由: 除去は取り込みの何十倍もかかる。実測: ID だけで filter-repo 1 回、
  その後もタイトル・日時が出続けた。**検査で後追いする方法は無い** — 拒否
  リストは「載っている名前」しか止められず、話タイトルは載らない
- 悪い例: 画面のログに出た実在の話タイトル (`第１節　架空の蔵書目録 - ハーメルン`
  のような形の実物) をテストに貼る / 良い例: `第１節　話1 - ハーメルン`
  (形式は保ち、内容は宣言済み)

### DATA-2: 写すのは形式であって値ではない [MUST] [構造]
- 対象: 全言語
- 規則: 実物から写してよいのは**形式** (タグ構造・フィールド名・区切り・
  日時の書式)。**値**は写さない。判定法は「この値を別の値に変えてもテストが
  通るか」— 通るなら実データである必要がない
- 理由: テストが確かめているのは形式で、値はその入れ物。値を実物にしても
  検出力は 1 ビットも上がらず、漏れる面だけが増える
- 悪い例: `<time>` の中身に実物の掲載日時を秒までそのまま写す
  / 良い例: `<time>2020/01/02 03:04</time>` (合成値)

### DATA-3: 日時・数値・件数も内容である [MUST] [構造]
- 対象: 全言語
- 規則: 名前や ID だけでなく、**日時・座標・金額・件数**も置換する。名前を
  消して日時を残すのは、消していないのと同じ
- 理由: 秒単位の日時が 12 個並べば、それだけで元を特定できる。実測: 捕獲
  データを作る道具は ID・タイトル・URL を置換していたが**日時 15 個を素通し**
  しており、名前を見る検査では最後まで見つからなかった
- 悪い例: 全部ダミー名に置換した捕獲データが、実物の `publishedAt` を秒まで
  保持している / 良い例: 置換対象に日時を含め、順序だけ保った合成値にする

### DATA-4: コメントに観測した文字列を引用しない [SHOULD] [細部]
- 対象: 全言語
- 規則: 不具合や仕様を説明するコメントで、**実際に観測した文字列をそのまま
  引用しない**。ダミーで書いても説明は成立する
- 理由: コメントは検査の網から外れやすく (語彙チェックは文字列リテラルを見る)、
  しかも「なぜこの値なのか」を誰も疑わない
- 悪い例: `// サイトはタイトルを "<実物のタイトルと実掲載日時>(改)" にしてしまう`
  と観測値をそのまま引用する / 良い例: `// サイトはタイトルを
  "話1 2020/01/02 03:04(改)" のように連結する`

### DATA-5: 実データが入る口を 1 か所に絞る [SHOULD] [構造]
- 対象: 実データを扱う PJ
- 規則: 実物を取り込む必要があるのは**捕獲データだけ**にする。捕獲は必ず道具を
  通し、道具が置換する。手書きのテストは**実物を画面に出しながら書かない**
- 理由: 口が 1 つなら漏れの検査も 1 か所で済む。手書きのテストに実物が混じると
  検査対象が全ファイルに広がり、1 件ずつ人が判定するしかなくなる
- 悪い例: 実ページを開きながらテスト用 HTML を書き起こす
  / 良い例: 捕獲 → 道具で置換 → その出力をテストに使う

機械チェックは無い。**DATA-1〜5 は検査で代替できない**のがこのルールの要点で、
拒否リストと語彙チェックは「取り込んでしまった後」に効く網でしかない。
